# À propos de Project NOMAD

Project NOMAD (ou simplement « NOMAD ») a été lancé en 2025 par Chris Sherwood, de [Crosstalk Solutions, LLC](https://crosstalksolutions.com). Son objectif n’est pas de créer un simple outil supplémentaire pour stocker des ressources hors ligne, mais de permettre à chacun de construire son propre « ordinateur de survie ». À l’origine, NOMAD était un acronyme construit à partir de *Node for Offline Maps, Archives, and Data* ; aujourd’hui, nous l’appelons simplement NOMAD.

Contrairement à de nombreux ordinateurs de survie hors ligne conçus pour du matériel très modeste, Project NOMAD encourage l’utilisation d’une machine suffisamment puissante, idéalement équipée d’un GPU, pour profiter pleinement des outils d’intelligence artificielle. Consultez le [Guide matériel](https://www.projectnomad.us/hardware) pour des recommandations adaptées à trois niveaux de budget.

Depuis sa première publication, NOMAD s’est enrichi d’un chat IA intégré, d’une base de connaissances permettant de répondre à partir de documents, d’un test de performance avec classement communautaire, de collections de contenus sélectionnés et d’un assistant de configuration guidée.

Project NOMAD est un logiciel libre publié sous [licence Apache 2.0](https://github.com/Crosstalk-Solutions/project-nomad/blob/main/LICENSE).
